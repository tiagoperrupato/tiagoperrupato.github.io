# Tiago Perrupato — Personal website

A two-page portfolio in English, implemented with original HTML and CSS. Public projects are listed with comparable visual weight. The first item is Enter Decision Platform; private research and employment are described in the experience section.

## Local preview

Run `python3 -m http.server 4173` from the published repository root, then visit http://127.0.0.1:4173/. In the local authoring folder, use `python3 -m http.server 4173 --directory dist`.

## Update content

- `index.html`: profile, project summaries, experience and contact.
- `projects/enter-unicamp-hackathon/index.html`: project notes and confirmed AI Core contribution.
- `assets/style.css`: layout, colors and responsive breakpoints.
- `assets/tiago-perrupato-resume.pdf`: English one-page resume.
- `sitemap.xml`: add a URL when publishing another complete page.

Keep individual contributions and team results distinct. Preserve the user-approved Recod description in the CV. OpenEnv stays on the GitHub profile, but is excluded from this website and the CV at Tiago's request.

## Images

The portrait is Tiago's selected LinkedIn photograph. The project image is the preview of the team's public walkthrough: https://youtu.be/1ZYb-6MXH5U. No code, wording or assets were taken from the colleague reference portfolios.

## Publishing

GitHub Pages serves the main branch at https://tiagoperrupato.github.io/. Changes to source files trigger a build. Confirm the latest deployment succeeds before reporting a publication complete.
